# 余量持续改进路线

更新：2026-09-05。建仓并不意味着 AI 分析已上线。

## M0：独立仓库基线（本次）

- 建立独立主分支，保留原中文界面、规则原型及合成例子。
- 私人数据、非官方连接脚本和第三方 checkout 与版本控制隔离。
- 提供启动、检查、隐私边界、来源归属和后续路线文档。
- 私有托管；公开发布与许可证留待单独确认。

## M1：接上可信数据（下一步，尚未实施）

- 从现有本机数据库读取标准化日汇总，不重建采集系统。
- 经确认补足合理历史；拟用 28 天统计窗口，不将该窗口描述为医学标准。
- 区分缺失、零、未同步和未结束的当天；统一时间区间与单位。
- 对源数据与计算结果抽查；缺历史时不制造个人基线。
- 公开核心同时保留无需 Garmin 登录的文件输入。

验收：页面显示真实数据日期和覆盖范围，失败不能伪装为今天已同步。

## M2：每日解读与纠错（尚未实施）

- 拆分可测试的计算与解释模块，重新验证现有经验阈值。
- 今日变化、引用依据、结合原计划的可选调整。
- 记录是否采纳和活动后体感，不以一次点击代表长期价值。
- 本地/云模型接口可替换，明确敏感信息范围和费用；默认不外发数据。

验收：可以指出每条建议的依据；遇到缺失、陈旧、疼痛或生病迹象有明确处理；不输出诊断或伪造健康指标。

## M3：每周回顾与独立试用（尚未实施）

- 每周持续变化、建议是否有效、下周一个可验证调整。
- 依据 DOGFOOD.md 积累自用记录，收集独立用户的具体失败案例。
- 手机安全访问与活动记录接入按实际需要排期，不开放数据库公网端口。

## M4：公开发布（需再次确认）

- 选择公开许可证，复核第三方许可及来源声明。
- 扫描所有提交历史、演示和文档，排除真实健康记录、定位、私人截图、密码与令牌。
- 新用户只用合成数据即可启动体验；不要求提交 Garmin 密码。
- 用户明确确认后才切换可见性、发布演示或进行社区推广。
- 分开观察 Star、成功启动、持续使用与决策帮助；没有独立需求时缩小方向。
