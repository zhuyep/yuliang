# 余量持续改进路线

更新：2026-09-10。公开预览不意味着产品价值、AI 效果或医学有效性已经得到验证。

## M0：独立仓库基线（本次）

- 建立独立主分支，保留原中文界面、规则原型及合成例子。
- 私人数据、非官方连接脚本和第三方 checkout 与版本控制隔离。
- 提供启动、检查、隐私边界、来源归属和后续路线文档。
- MIT 许可与公共预览所需的隐私、来源和贡献边界已补齐。

## M1：接上可信数据（已实现本机适配与质量检查）

- 从现有本机数据库读取标准化日汇总，不重建采集系统。
- 经确认补足合理历史；拟用 28 天统计窗口，不将该窗口描述为医学标准。
- 区分缺失、零、未同步和未结束的当天；统一时间区间与单位。
- 对源数据与计算结果抽查；缺历史时不制造个人基线。
- 公开核心同时保留无需 Garmin 登录的文件输入。

已实现：页面显示数据日期和实际覆盖范围，失败不回退为冒充真实的示例。历史回填不等于源端一定存在完整历史；实际有效天数按返回记录显示。仅接五类日指标，活动/压力分析仍未覆盖。

## M2：每日解读与纠错（本机闭环已实现；实际模型未启用）

- 拆分可测试的计算与解释模块，重新验证现有经验阈值。
- 今日变化、引用依据、结合原计划的可选调整。
- 记录是否采纳和活动后体感，不以一次点击代表长期价值。
- 本地/云模型接口可替换，明确敏感信息范围和费用；默认不外发数据。

已实现：可核对的每日事实、依据追问、主动保存与补记反馈、数据质量与不适边界；可选本地模型接口和合成协议测试。尚待：用户选择模型和数据许可、实际模型运行与解释质量验收。云模型没有接入，规则解释不能声称是生成式 AI。

## M3：每周回顾与独立试用（尚未实施）

- 每周持续变化、建议是否有效、下周一个可验证调整。
- 依据 DOGFOOD.md 积累自用记录，收集独立用户的具体失败案例。
- 手机安全访问与活动记录接入按实际需要排期，不开放数据库公网端口。

## M4：公共预览（2026-09-10 已通过发布前审查）

- 采用 MIT 许可证，复核第三方许可及来源声明。
- 已扫描全部现有提交历史、演示和文档，未发现真实健康记录、定位、私人截图、密码与令牌。
- 新用户只用合成数据即可启动体验；不要求提交 Garmin 密码。
- 以公共预览收集失败案例，不把发布、CI 或 Star 当成采用证据。
- 分开观察 Star、成功启动、持续使用与决策帮助；没有独立需求时缩小方向。
