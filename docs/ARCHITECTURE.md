# 架构与代码归属

## 当前：独立应用核心

| 部分 | 位置 | 当前能力 |
| --- | --- | --- |
| 交互 | index.html、styles.css、favicon.svg | 中文响应式页面 |
| 原型逻辑 | app.js | 规则建议、输入检查、会话内反馈与计划 |
| 合成输入 | data/example-*.json | 演示场景，不是真实用户健康记录 |
| 开发服务 | scripts/serve.mjs | 仅本机，只提供明确允许的前端文件 |
| 仓库检查 | scripts/check-repo.mjs | 检查待提交路径、符号链接、常见凭证及个人路径 |

根目录中可能还有本机实验文件。它们不因位于同一目录而成为本仓库的一部分。尤其是 garmin-grafana/ 保持自己的 Git 仓库与本机数据存储，不纳入这里的提交。

## 拟议：可替换的数据与模型接口

1. 用户本地文件或可选只读数据适配器，输出统一日指标。
2. 确定性分析模块，计算有效天数、覆盖率、个人基线、趋势与数据新鲜度。
3. 解释模块接收必要的计算摘要，结合用户计划与体感，输出带依据的解读。
4. 反馈存储记录建议、选择与结果，支持回顾错误。

上述四层尚未完成接通。模型没有 Garmin 凭证，不获得任意数据库查询或训练计划写入权限；云模型默认关闭，启用服务和允许发送的字段须经用户确认。

公开核心首先支持本地文件输入。个人非官方连接实验不作为公开多人授权方案；后续官方接入须单独核验资格、地区覆盖与服务条款。
